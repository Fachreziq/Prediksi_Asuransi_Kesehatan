# Prediksi Biaya Asuransi Kesehatan Berdasarkan Usia, BMI, dan Kebiasaan Merokok Menggunakan Regresi Linear (Streamlit)

## Cara Menjalankan di Lokal
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Cara Deploy ke GitHub & Streamlit Community Cloud
1. Upload `app.py`, `requirements.txt`, `insurance.csv`, dan `Prediksi_Biaya_Asuransi_Regresi_Linear.ipynb` ke repository GitHub Anda.
2. Buka [share.streamlit.io](https://share.streamlit.io/), login dengan GitHub, klik **Create app**.
3. Pilih repository, branch `main`, dan **Main file path**: `app.py`, lalu klik **Deploy**.
